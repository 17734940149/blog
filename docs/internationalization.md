# 中英文内容维护

导航中的 EN 切换英文界面，点击“中”恢复中文。语言偏好以同站 Cookie 保存一年，切换时保留当前页面和筛选条件；后台的按钮、提示和日期也随语言变化。

个人资料、项目与文章的英文由管理员在后台手动填写。英文是可选内容：某个英文字段留空时，只将该字段回退为对应中文，其余已填写的英文仍正常显示。列表未填写或某个对应项留空时，按中文列表的索引逐项回退。修改内容后直接保存即可，无需启动额外服务、下载模型或等待自动翻译。

## 可维护的英文内容

| 后台内容 | 可选英文字段 |
| --- | --- |
| 文章 | 标题、摘要、Markdown 正文、分类、标签 |
| 项目 | 名称、介绍、技术栈 |
| 站点资料 | 站点标题、标语、描述、作者名、简介、所在地、关于正文、近况、身份、技能、博客初衷 |

例如，仅填写文章英文标题而不填写英文正文，英文页面会显示英文标题与中文正文。中文与英文 Markdown 正文分别维护，代码片段、链接和排版由作者自行填写。文章地址、邮箱、项目链接等通用数据继续共用。

## 分类、筛选与搜索

- 分类和标签的筛选值保持中文源值，切换语言不会改变筛选目标。英文分类名称优先使用该分类公开文章中按稳定 ID 排序的第一个非空英文分类名；未填写时使用中文。
- 搜索在中英文界面均匹配中文原文与手动填写的英文标题、摘要、正文、分类和标签。草稿与未来发布的内容不会进入公开搜索。
- 中英文内容均保存在同一 SQLite 数据库，随现有备份一起保存。已有内容未填写英文时，继续正常显示中文；历史机器翻译缓存不作为手动英文内容使用。

界面语言包位于 `src/lang/zh` 与 `src/lang/en`，两侧 key 路径保持一致。界面语言与内容语言分别维护，公开接口按当前语言返回用于展示的字段，后台保留中文与英文供编辑。
